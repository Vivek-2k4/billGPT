# BillGPT

BillGPT is a price comparison platform that compares products and services across multiple providers and recommends the best deal and payment method.

## Features

- User Authentication
- Deal Comparison
- Cheapest Deal Detection
- Best Payment Method Recommendation
- Search History
- Responsive UI

## Tech Stack

Frontend:
- React
- TypeScript
- Tailwind CSS
- Axios

Backend:
- FastAPI
- SQLite
- SQLAlchemy

## Run Frontend

npm install
npm run dev

## Run Backend

pip install -r requirements.txt
uvicorn app.main:app --reload
